# HelpVloggers.com - Vlogging Products SEO Infrastructure Package

This directory contains the complete SEO configuration and data structure for **HelpVloggers.com** (Vlogging Gear & Creator Product Aggregator & Review Hub).

## File Manifest & Instructions

1. `robots.txt`: Deploy to public root folder. Blocks `/go/` affiliate redirect routes while providing XML sitemap path to search crawlers.
2. `sitemap.xml`: Base XML sitemap for Vlogging Category Hubs, Product Review Spokes, and Head-to-Head Comparisons.
3. `seo-keywords.json`: Vlogging gear keyword strategy database categorized by search volume, search intent, and target category URLs.
4. `site-config.json`: Master site parameters, page title templates, meta tags, and affiliate tracking configuration.
5. `schema-templates.json`: JSON-LD Schema templates for Google Rich Snippets (`Product`, `BreadcrumbList`, `AggregateRating`).
6. `content-strategy.md`: Publishing guidelines for creator-focused product reviews, comparison matrices, and audio/video interactive elements.
